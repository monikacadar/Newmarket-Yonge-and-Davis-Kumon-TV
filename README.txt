KUMON TV WEBPAGE V3

This version fixes the black-screen problem.

IMPORTANT:
The black screen after Announcements is the VIDEO screen.
If there is no valid file at media/promo.mp4, V3 automatically skips it after a few seconds and returns to Welcome.

To use a video:
1. Put an MP4 in the media folder.
2. Rename it exactly promo.mp4
3. Reopen index.html.
4. The video plays muted for its full duration, then the playlist returns to Welcome.

For testing WITHOUT video, simply leave the media folder as-is.
